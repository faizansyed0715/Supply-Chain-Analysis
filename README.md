# Supply-Chain-Analysis
Customer, Product, and Profitability Performance Analysis in Supply Chain Operations


### 📌 Project Overview

This project analyzes supply chain operations using customer, product, sales, profitability, shipping, and delivery data.

The objective is to identify key business insights related to sales performance, customer distribution, product performance, profitability, shipping modes, and delivery status.

### 🛠️ Tools & Technologies

- Power BI
- Data Cleaning & Transformation
- Data Visualization
- Exploratory Data Analysis
- Supply Chain Analytics

### 📊 Dashboard KPIs

- Total Sales: 36.78M
- Total Profit: 3.97M
- Total Customers: 20.652K
- Average Shipping Delay: 0.57

### 📈 Key Analysis

The dashboard provides analysis of:

- Sales by Category
- Sales by Region
- Sales by Shipping Mode
- Shipping Delay by Delivery Status
- Average Profit per Order by Shipping Mode
- Sales by Delivery Status
- Sales vs Profit by Product

### 💡 Business Insights

The analysis helps understand:

- Which product categories generate higher sales
- Which regions contribute the most revenue
- Which shipping modes generate the highest sales
- Delivery statuses associated with shipping delays
- Profitability across different shipping modes
- Relationship between product sales and profitability
